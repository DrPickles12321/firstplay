# FirstPlay demo script

The prepared silent/captioned draft runs **2:10**. Every product image is a genuine UI capture; recognition images are original fixtures, explicitly labeled. The build section presents actual source/check artifacts rather than recording the Codex app. Before final submission, replace or supplement that 18-second section with a brief recording of this Codex build thread/source view if available. The available automation cannot capture the Codex app window.

## 1. Keep the surprise. Keep the conversation. (8s)

A first playthrough is better with a community. One message can reveal the next discovery. FirstPlay screens what reaches the streamer while everyone keeps chatting.

## 2. Same channel. Different reading experience. (18s)

These are two real posts on an offline Twitch test channel. Ordinary chat contains the greeting and a gameplay instruction. The installed FirstPlay reader shows only the greeting, after actual EventSub transport and model screening. Viewers install nothing.

## 3. An unknown name stays out of the reader. (14s)

Here is a separate local run with no discoveries. Even a friendly reaction can reveal an unseen name. The model holds it for review, and the streamer never receives the raw message. Unreviewed messages expire.

## 4. Choose a source once. Clear discoveries follow. (15s)

Selecting a video starts recognition automatically. This recording contains original test labels, not game footage. The native Apple Vision helper reads supported text on this Mac. It adds the name and inventory-screen fact without unlocking a recipe or action.

## 5. Four frames. Two checks. One bounded fact. (10s)

Two consecutive checks must agree across four frames. The private evidence is inspectable. Missing context, weak text, a changed source or replayed evidence cannot accumulate proof.

## 6. Knowing the name does not permit instructions. (14s)

A fresh copy of the same reaction now passes because the name is known. Cook the Boomerang still stays hidden. The text model interprets meaning, and a separate policy gate enforces the playthrough rules.

## 7. Delivered means rendered, not read. (12s)

A viewer can check whether their message reached the protected reader. A real rendering acknowledgement produces the delivered marker. Approval alone is not delivery, and delivery does not mean the human streamer read it.

## 8. Undo restores the boundary. (10s)

Every automatic update has history and Undo. Correcting it restores the earlier knowledge, clears old approvals, and prevents the detector from immediately adding the same facts again.

## 9. Built and verified in this Codex session. (18s)

Codex developed the project from the policy decisions through authored context, contracts, Twitch integration, UI and regression tests. These are actual source and check artifacts from this build session. One hundred thirty controlled tests passed. No model was trained or fine-tuned.

## 10. Discover it together. (11s)

Today this is a useful desktop pilot, not whole-game protection. Screening takes several seconds, and recognition covers a narrow English opening. FirstPlay keeps the surprises while keeping the conversation.
