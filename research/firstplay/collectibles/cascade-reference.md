# Cascade Kingdom: all Moons and purple-coin references

Researched October 30, 2026. **Contains spoilers.**

**40 numbered Moon objectives, worth 42 units; 50 regional purple coins.** These are complete source indexes, not confirmed player knowledge or validated detection data.

## Purple-coin location groups

[Reference location guide](https://vandal.elespanol.com/guias/guia-super-mario-odyssey-trucos-y-consejos/monedas-moradas-reino-de-las-cataratas) · [Nintendo visual map](https://www.guiasnintendo.com/2c-switch/super-mario-odyssey/guia-super-mario-odyssey/monedas-02-reino-cataratas.html).

Ranges below follow the reference guide, not official in-game coin IDs. Other guides may number or group the same coins differently. First-visit access and exact geometry still need gameplay checks.

| Reference range | Quantity | Location summary |
|---|---:|---|
| 1–3 | 3 | Behind the arrival point, at the edge. |
| 4–6 | 3 | Ledge left of the starting area. |
| 7–9 | 3 | Ledge right of the starting area. |
| 10–12 | 3 | Cave beneath the waterfall. |
| 13–15 | 3 | Recess below the waterfall-crossing bridge. |
| 16–19 | 4 | Ledge near the large-stump checkpoint. |
| 20–22 | 3 | Ledge left of Talkatoo. |
| 23–25 | 3 | Rock to the T-Rex’s right. |
| 26–28 | 3 | Recess beneath the T-Rex area. |
| 29–31 | 3 | Left from the Stone Bridge checkpoint. |
| 32–34 | 3 | Up the checkpoint’s right-hand ledges. |
| 35–38 | 4 | Upper route near the end of the nearby challenge. |
| 39–41 | 3 | Left after crossing the bridge. |
| 42–47 | 6 | Two ledges toward the waterfall. |
| 48–50 | 3 | Floating platform near the boss area. |

**Total: 50 coins.** The six-coin range represents two nearby ledges; it is not six copies of one location.

A regional-coin counter increase indicates a quantity collected; it does not by itself identify which hidden group the player found. Detection needs spatial evidence or confirmation before revealing location-specific discussion.
